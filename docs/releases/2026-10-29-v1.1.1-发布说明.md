## 一、新增：Google Gemini 订阅配额监控

Gemini 的订阅配额没有 API，只能登录网页看。本版把「登录一次，长期监控」做进了 App。

### 你怎么用

1. 右键状态栏图标 → **设置…**
2. 「平台配置」区找到 **Google Gemini** 行 → 点「**登录**」
3. 弹出的窗口里完成 Google 账号登录（两步验证照常走）
4. 登录成功窗口自动关闭，该行显示绿色「已登录」

### 它给你看什么

| 状态栏 | 含义 |
|--------|------|
| `G 31` | Gemini 当前用量窗口已用 31%（绿色/黄/橙/红随阈值） |

点开 Popup 面板还能看到两个窗口：

- **当前用量**：主窗口，带重置倒计时（例：`重置于 3 小时 18 分 · 23:00`）
- **7d**：每周限额，带周重置时间（例：`已使用 5%`，重置 11月2日）

### 使用须知

- 登录态存在**本机**，只存 cookie，不存账号密码，不上传任何内容
- 抓取频率上限 **5 分钟/次**（比 API 平台慢，因为是渲染整个网页，不会高频访问 Google）
- 登录过期时状态栏 `G` 显示 `!`，同时弹系统通知提醒你重新登录
- 想换账号：点「退出登录」再重新「登录」

## 二、修复：MiniMax 重置倒计时一直是假的

### 现象

> 我实际验证 MiniMax 的剩余时间是 1 小时 56 分，此刻是 16:24，
> 预计下午 18 点左右恢复额度。但点开窗口显示的却是「重置于 4 小时 59 分，21:24」。

### 根因

代码找的是**不存在的字段**（顶层 `resetTime`、`interval_end_time`），
真实响应里两个都没有，于是每次都落到「抓取时刻 + 5 小时」的兜底值——
也就是说，那个倒计时跟服务端窗口毫无关系，只是把当前时间往后加了 5 小时。

真实字段是 `model_remains[].end_time`（毫秒时间戳，窗口真实结束时刻），
旁边还有 `remains_time`（剩余毫秒）可以互证。

### 修复后

倒计时直接来自服务端窗口：**18:00 → 23:00 的窗口，现在就显示「重置于 3 小时 18 分 · 23:00」**。

顺带把 MiniMax 一直没用的**周窗口**也接上了，Popup 里多一行「7d」。

> Kimi 与智谱 GLM 的倒计时本来就取自服务端（`resetTime` / `nextResetTime`），已核对，无需改动。

## 三、状态栏新形态

| 情况 | 显示 |
|------|------|
| 四平台**全绿** | `35 60 12 31` —— 只留绿色数字，不带平台字母（安静模式） |
| 任一平台非绿 | `K 35 M 60 G 12 Z 31` —— 字母回归，一眼看出是谁高了 |
| 某平台打满（红色） | `K 100 (1h56m)` —— 红色数字后附括号倒计时，一眼知道还有多久恢复 |

括号里的倒计时取自该平台窗口的**真实重置时刻**（也就是上面第二节修准的那个值），紧凑格式：
`1h56m` / `45m` / `12s`。

## 五、技术要点（给开发者）

### 新增第 2 种平台形态

前三个平台是 **API Key 型**（Key 存 Keychain，定时打 API 解析 JSON），
Gemini 是**网页会话型**，因此新增了一条独立链路：

| 维度 | API Key 型 | 网页会话型（Gemini） |
|------|-----------|-------------------|
| 鉴权 | Keychain | Google 网页登录，cookie 存 WebKit 存储 |
| 取数 | URLSession | WKWebView 加载页面 + 注入 JS 读 DOM |
| 刷新 | 30s–5m 智能节流 | 独立 5 分钟下限 |
| 过期 | 401 → 提示配 Key | cookie 失效 → 引导重登 |

### 三个关键坑（已在代码注释与文档中固化）

1. **内嵌浏览器登录 Google 必须伪装成完整桌面 Safari UA**——
   伪装 Chrome UA 会被判「此浏览器或应用不安全」（WKWebView 里没有 `window.chrome`、
   不发 client-hints，特征自相矛盾）；伪装本机 Safari UA 则完整走通登录与两步验证。
2. **「是否已登录」必须看认证 cookie**（`SID/SSID/HSID/SAPISID`）——
   登录墙页面本身也在 `gemini.google.com` 域上，只看域名会把"停在登录墙"误判成"登录成功"。
3. **数据不在初始 HTML**，Gemini 是 React SPA，必须等 DOM 渲染出
   `[data-testid="current-usage"]` 再提取，不能固定 sleep。

## 七、已知限制

- Gemini 依赖 Google 网页结构：Google 改版时可能需要更新解析器
  （已用 `data-testid` 主锚 + 两级兜底候选链降低风险）
- Gemini 抓取走 WKWebView，App 常驻时会有一个 WebKit 子进程（约 156MB）
- App 未启用 App Sandbox；Gemini cookie 存在 `~/Library/WebKit/app.quotamonitor`
- 未配置的平台在状态栏仍显示 `--`（此时不进入安静模式）
